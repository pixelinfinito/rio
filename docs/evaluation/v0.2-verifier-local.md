## Live Cloudflare and OpenRouter smoke

Rio deployed the embedded Worker through native Cloudflare APIs using cf OAuth,
provisioning/reusing D1, R2, Queue, Review/Migration Workflows, an authenticated AI
Gateway and a Sandbox Container application. Repeated `rio deploy` reused the
resources and forward migration ledger. The Worker health endpoint returned
version 0.2.0/protocol 1; an unauthenticated review request returned HTTP 401.
Account IDs, resource IDs and credentials remain in user configuration, outside
checked-in runtime configuration. Headless deployment used the explicit private
file credential store.

The initial pinned [smoke record](v0.2-hosted-smoke.json) contains a benign Python fixture,
report, vote summaries, usage and runner outcomes. GPT-4.1 Mini generated a
hypothesis; three independent Claude Haiku 4.5 voters each completed blind and
disclosed passes through OpenRouter and authenticated Cloudflare AI Gateway.
Caching and gateway log collection were disabled.

The fixture removes a zero-count guard from `average(total, count)`. Two voters
supplied valid head graph citations, establishing `static_proven` quorum. The
third supplied an unsupported citation and was limited to `plausible`; it did not
contribute proof. All three blind comparisons were `related`. The CLI returned
exit 1 for the defect. Generation cost was $0.001090188 and verification cost was
$0.02453517, as reported by OpenRouter. Both trusted graph and checks jobs exited
successfully in Cloudflare Containers. Missing Python tools/project lint rules
and the offline dependency audit remain explicitly skipped, making the overall
report incomplete. The smoke establishes deployment and inference behavior; it
does not establish precision or complete project-tool coverage.

Earlier live attempts exposed missing Git metadata in runner snapshots, a deleted
hunk omitted from the head graph, the Workers fetch receiver requirement and
provider output/category errors. Regression fixes preserve artifact validation:
fabricated executions cannot establish reproduction, category upgrades remain
invalid, and model prose/XML never executes as a host tool call. Identical repeated
JSON objects from a provider are collapsed to one tool request; differing answers
remain malformed. A regression test verifies that duplicate tool calls execute once. Failed attempts
remain available in the private hosted audit.

The paired public release runner image is configured in the release workflow.
This workspace used a locally built image copied to the account registry and
pinned by digest. No release or public GHCR image was published here. Native mock
tests cover fresh/repeated deployments, account isolation, private credentials,
API error redaction and offline dry-run without a source checkout or Node tools.

select `openrouter/anthropic/claude-sonnet-5.5` for generation and
`openrouter/openai/gpt-6.1-sol` for verification. Both exact IDs were listed in
OpenRouter's live model catalog on 2026-11-06. The profile retains three voters,
quorum two and the existing token budgets. All 15 profile discovery/resolution
tests and six native deployment tests passed after this configuration change.

An [initial modern-model failure record](v0.2-hosted-modern-initial.json) retains
one completed static-proof vote and two incomplete votes. Real Cloudflare jobs
showed a passing base reproduction and a failing head reproduction, but missing
votes correctly prevented quorum and the CLI returned exit 4. Duplicate provider
JSON retained in conversation history and an initial `python` command instead of
the image's `python3` consumed the bounded allowance. The adapter now stores only
the accepted protocol JSON in conversation history, preserving raw provider output
and all usage charges in audit, and the tool prompt identifies `python3`. Identical
duplicate JSON is executed once; differing answers remain invalid. Worker tests
verify the dispatch count and normalized history. No budget or artifact requirement
was weakened.

The [final modern-model smoke](v0.2-hosted-modern-smoke.json), review
`9288fc78-48ad-45cf-8291-a983f2864e5d`, completed all three independent voters.
Each supplied valid passing-base and failing-head Cloudflare Container executions;
all three validated at `reproduced`, with `related` blind matches and no split.
The CLI returned exit 1 for the defect. Provider-reported generation cost was
$0.02363922 and verification cost was $0.039740085. The review retained the existing
incomplete deterministic-check status for unavailable Python tools, missing lint
configuration and the offline dependency audit. No verifier votes were missing.
This verifies the requested model configuration through the deployed gateway and
runners; it remains one fixture, outside the independent precision acceptance gate.

## Review fixes redeployment

A full implementation review found ten defects, all fixed with regression tests:
runner completions are now signed and verified over the exact transmitted bytes;
the self-hosted runner survives per-job failures, drains oversized output and
marks host-side failures `runner_failed`, which never counts as reproduction
evidence; saved endpoint tokens are bound to their configured URL; `--fork`
without an endpoint is rejected; evidence cannot inject Markdown; snapshot uploads
preflight server limits; failed deployment migrations retry under a new instance;
graph seeding tolerates cross-language renames and falls back to the nearest shared
ancestor; partial reports respect `fail_on.incomplete`; and malformed verifier
audits exit 4 instead of passing.

After redeploying the Worker and runner image, the [post-fix hosted smoke](v0.2-hosted-review-fixes-smoke.json),
review `d1398a9b-8829-45e2-8a68-5723df62862a`, reproduced the fixture defect with
two of three votes at `reproduced` (all blind matches `related`, no split) using
passing base and failing head Container executions, all with outcome `exited`. The
third voter returned malformed model output and was recorded as an incomplete vote;
the report is `incomplete` and the CLI returned exit 1 for the defect.
